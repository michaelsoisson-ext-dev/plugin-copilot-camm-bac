# Operational Workflow

1. **Requirements extraction** break down the jira ticket into a clear [Behavor-driven Development Flow](references/bdd-principles.md)

2. Define behavior before implementation and write acceptance tests that stakeholders can understand helped with [Bdd scenario](references/bdd-scenario.md)

3. Output the result as markdwon checklist using `[]` for each step
   following the [`Acceptance Criteria Format`](references/bdd-template.md) template and save it `.ai-camm-bac/plans/bdd-plan-<unique-name>.md` at then end.
